# 项目二：垃圾邮件智能过滤工具

> **难度等级**：Lv.2 入门级 | **总课时**：3 课时（每课时 45 分钟）  
> **技术栈**：Python 3.10+ · pandas · scikit-learn · matplotlib · pytest  
> **数据集**：Apache SpamAssassin Public Corpus（6 个 tar.bz2，ham 4,153 / spam 3,296）

---

## 项目目标

你需要构建一个能够识别垃圾邮件的自动过滤工具。

借助 AI 完成全流程：

**数据探索 → 文本清洗 → 特征提取 → 规则过滤 → 朴素贝叶斯 → 模型评估 → 工具封装**

核心能力：

**文本预处理 · 特征工程 · TDD · 规则分类 · 朴素贝叶斯 · 模型验收**

---

## 数据集

- **来源**：Apache SpamAssassin Public Corpus
- **文件**：6 个 `.tar.bz2`（解压后每封邮件为独立文件，RFC 2822 格式）
- **规模**：ham 4,153 / spam 3,296（共 7,449 封）
- **标签**：
  - `ham`：正常邮件（`easy_ham/`、`easy_ham_2/`、`hard_ham/` 目录）
  - `spam`：垃圾邮件（`spam/` 目录）
- **格式**：每封邮件为独立文件，含邮件头 + 正文（可能含 HTML/附件）
- **特点**：类别较平衡，spam 约占 44%

数据加载后统一为：

```text
label               # 按目录判定
raw_message         # Subject + 正文拼接（不含邮件头）
cleaned_message     # 清洗后文本
```

## Lesson 1：规格、测试与文本清洗

### 你要做什么

1. 加载数据并统计类别分布；
2. 检查缺失值和消息长度；
3. 确认 `raw_message` 与 `cleaned_message` 数据契约；
4. 使用 `spec_template.md` 生成并审查 `spec.md`；
5. 使用 `test_strategy_template.md` 生成并审查 `test-strategy.md`；
6. 对文本清洗执行 Red–Green–Refactor；
7. 生成 `cleaned_data.csv`。

文本清洗至少覆盖：

1. 转小写；
2. 去除 HTML；
3. 去除 URL；
4. 去除邮箱；
5. 去除电话号码；
6. 处理标点和特殊符号；
7. 合并多余空格；
8. 去除停用词；
9. 处理清洗后空文本。

### 阶段提交文件

## Lesson 2：特征、规则与朴素贝叶斯

### 你要做什么

1. 提取六类特征：
   - 消息长度；
   - 大写字母占比；
   - 感叹号数量；
   - 关键词命中；
   - 数字数量；
   - 货币符号；
2. 实现规则过滤器；
3. 明确特征权重和判定阈值；
4. 使用 `CountVectorizer + MultinomialNB` 实现朴素贝叶斯分类器；
5. 固定训练集和测试集；
6. 执行模型 train/predict Smoke Test；
7. 检查数据泄漏。

特征来源：

| 特征 | 数据源 |
|---|---|
| 长度、大写、感叹号、数字、货币符号 | `raw_message` |
| spam 关键词 | `cleaned_message` |
| CountVectorizer | `cleaned_message` |

实验要求：

```text
random_state = 42
stratify = y
positive label = spam
```

Vectorizer 只能在训练集上 fit。

   - Recall；
   - F1；

2. 使用固定实验协议比较规则过滤和朴素贝叶斯；

4. 分析 False Positive 和 False Negative；

7. 撰写 `analysis_report.md`；

建议模型验收门槛：

| 指标 | 门槛 |
|---|---:|
| Accuracy | ≥ 95% |
| spam Precision | ≥ 90% |
| spam Recall | ≥ 85% |

## 评分标准

总分 100 分。

| 评分维度 | 分值 | 评分重点 |
|---|---:|---|
| Spec、测试策略与数据契约 | 15 | 需求明确、raw/cleaned 定义正确 |
| 文本清洗与特征提取 | 20 | 清洗正确、特征来源正确 |
| 规则过滤与朴素贝叶斯 | 25 | 规则可解释、Pipeline 正确、无明显泄漏 |
| 测试与模型验收 | 15 | TDD 有效、指标可复现、实验协议固定 |
| 图表与分析报告 | 15 | 图表一致、FP/FN 分析具体 |
| 工程结构与 AI-log | 10 | 包可运行、目录完整、人工判断有效 |

### 好的提交

- 可以通过 `pytest -q`；
- 可以通过 `python main.py` 重新生成结果；
- `raw_message` 始终保留；
- 每个特征使用正确的数据源；
- Vectorizer 只在训练集上 fit；
- 两种方法使用同一测试集；
- Accuracy、Precision、Recall、F1 可以复现；
- FP/FN 分析来自真实样本；
- `AI-log.md` 能体现学生真实的采纳、修改和拒绝判断。

### 不好的提交

- 覆盖或删除 `raw_message`；
- 从清洗文本计算大写、标点或货币符号；
- 在完整数据上 fit 后再拆分；
- 反复使用最终测试集调参；
- 只报告 Accuracy；
- 图表与指标不一致；
- 为提高指标修改标签；
- `AI-log.md` 只有聊天截图或“AI 说得对”。
