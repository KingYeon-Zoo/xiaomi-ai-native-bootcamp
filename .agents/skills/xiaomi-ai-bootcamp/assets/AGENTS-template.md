# 项目级 Codex 入口

<INSTRUCTIONS>
1. 开始任何规划、开发、审查、测试或提交工作前，必须完整读取 `docs/engineering-constraints.md`。
2. 如果 `docs/engineering-constraints.md` 不存在，先创建 `docs/`，再基于小米训练营模板生成该 Markdown 文件；在此之前不得写业务代码。
3. 除根目录 `README.md`、`AGENTS.md` 和课程明确要求的 `CLAUDE.md` 外，所有开发过程文件必须使用 Markdown 并写入本项目 `docs/` 或其子目录。
4. 不在根目录复制 Spec、Design、Tasks、AI Log、测试记录、决策、会议、复盘或答辩正文。
5. 发生规则冲突时，以当前任务原文和最新人工决策为准，并把冲突、判断和验证写入 `docs/` 对应记录。
6. 所有训练营文档使用简体中文。
</INSTRUCTIONS>
