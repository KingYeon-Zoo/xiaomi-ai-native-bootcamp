# Spec：Day2 学习任务清单助手

## 目标（Goals）

1. `today` 无输入，输出五个 Day2 文件及已提交/未提交状态。
2. `submit <文件名>` 接受任务文件名并持久化已提交状态，文件名大小写不敏感。
3. `check` 无输入，只输出尚未提交的文件；全部提交时输出完成提示。
4. 状态文件不存在、JSON 损坏或字段不完整时自动重建，并给出明确提示。

## 非目标（Non-Goals）

1. 不提供 Web UI、登录、多用户或团队协作。
2. 不支持增加、删除或重命名五个固定任务。
3. 不保存提交时间、操作者或历史版本。
4. 不使用数据库、第三方 CLI 框架或远程 API。

## 边界条件

1. 未提供子命令：打印帮助并返回退出码 2。
2. `submit` 文件不在清单：不修改状态，返回退出码 2。
3. 重复提交：保持原状态，输出“已提交过”，返回退出码 1。
4. 状态文件损坏、字段缺失或值不是布尔类型：重建五个未提交状态。
5. `README.md` 等文件名大小写变化：映射回清单中的规范名称。

## 验收标准

1. 运行 `python3 cli.py today`，退出码为 0，输出恰好五个任务和五个状态标记。
2. 在空状态下运行 `python3 cli.py submit README.md`，输出 `✅ README.md 已提交`；随后 `check` 不再列出 README。
3. 运行 `python3 cli.py submit fake.txt`，输出“不在任务清单中”，退出码为 2。
4. 把状态文件写成无效 JSON 后运行 `today`，输出“状态文件损坏”，并生成合法的五字段 JSON。
5. 运行 `python3 -m unittest discover -s tests -v`，8 条用例全部通过。
