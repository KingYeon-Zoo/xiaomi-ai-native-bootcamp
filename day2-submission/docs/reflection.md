# Reflection — Day2 AI Native 训练营

## 今天最大的认知变化

我在核对 15 张 mission 与现有 `day2-workflow` 时发现，“已有文件”不等于“可提交”：例如课堂目录里使用 Windows 路径和 PowerShell，Spec Coding 的规则文件叫 `CLAUDE.md`，但 mission 明确要求 `AGENTS.md`。这改变了我对复用的理解——复用必须先重新验证接口、命名、平台和证据，而不是直接复制。

## 今天最困难的地方

最困难的是同时满足“Eval 至少保留一次失败分析”和“最终测试全部通过”。如果只记录最终绿色结果，无法证明能定位失败；如果故意让最终用例失败，又会破坏可交付性。最终选择记录修复前的大小写文件名失败，再修复 `cli.py` 并把最终状态更新为 PASS，让失败证据和最终质量同时成立。

## 如果再学一遍

我会在阅读第一张 mission 后立即建立“要求—文件—测试”追踪表，并在每完成一个模块时更新根检查脚本。这样能更早发现 `AGENTS.md` 命名、同桌评审证据、AI 审查 finding 字段等跨章节要求，减少最后集中补证据的风险。
