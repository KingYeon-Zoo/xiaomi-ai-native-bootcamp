# AI Log — 提交检查助手

## 第 1 条：状态优先级

| 字段 | 内容 |
|------|------|
| **目的** | 明确文件警告与测试失败同时出现时如何判定。 |
| **输入** | mission 要求的三状态以及失败兜底示例。 |
| **建议** | AI 建议按问题数量累计后选择状态。 |
| **人工判断** | 修改为 BLOCKED 优先于 WARNING，避免测试失败被文档警告稀释。 |
| **验证** | `test_failed_test_is_blocked` 验证任一失败测试直接 BLOCKED。 |

## 第 2 条：命令执行安全

| 字段 | 内容 |
|------|------|
| **目的** | 运行用户指定测试但避免 shell 注入。 |
| **输入** | 测试命令需要可配置，代码审查又要求检查任意执行风险。 |
| **建议** | AI 建议使用 `shell=True` 兼容管道命令。 |
| **人工判断** | 拒绝；用参数数组和 `shell=False`，牺牲管道语法换取清晰边界。 |
| **验证** | 自动测试覆盖正常命令和超时，源码未设置 `shell=True`。 |
