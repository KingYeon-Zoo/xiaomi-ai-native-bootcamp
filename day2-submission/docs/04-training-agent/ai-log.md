# AI Log — 训练营助教 Agent

## 第 1 条：Validator 是否必经

| 字段 | 内容 |
|------|------|
| **目的** | 防止工具有返回就直接宣布成功。 |
| **输入** | mission 数据流要求和资料外编造风险。 |
| **建议** | AI 建议简单请求可跳过 Validator 降低延迟。 |
| **人工判断** | 拒绝；本地校验成本极低，来源为空、success=false、BLOCKED 都必须统一处理。 |
| **验证** | `agent-design.md` 将 Validator 放在所有工具与 Answer 之间，13 条测试覆盖异常状态。 |

## 第 2 条：路径校验

| 字段 | 内容 |
|------|------|
| **目的** | 允许检查目录但防止任意文件读取。 |
| **输入** | validator 接收 project_dir，安全清单要求防路径逃逸。 |
| **建议** | AI 建议只检查 `..` 字符。 |
| **人工判断** | 修改为 `Path.resolve()` 后检查是否位于 allowed_root；符号链接和绝对路径都按解析结果判断。 |
| **验证** | `test_path_outside_allowed_root_is_blocked` 使用两个独立临时目录并得到 BLOCKED。 |

## 第 3 条：RAG 无匹配语义

| 字段 | 内容 |
|------|------|
| **目的** | 区分“工具失败”和“资料中没有答案”。 |
| **输入** | 空知识库、资料外查询、正常查询三种路径。 |
| **建议** | AI 建议三种情况统一 `success=false`。 |
| **人工判断** | 资料外查询保留 success=true 但 sources 为空，表示工具正常完成检索；知识库缺失才是工具失败。 |
| **验证** | 四条 RAG 测试分别验证正常来源、资料外拒答、缺库失败和空输入。 |
