# Project 2 AI 协作日志

## Session 1：raw/cleaned 数据契约

| 字段 | 内容 |
|---|---|
| 目的 | 避免清洗破坏人工特征，同时不把邮件头泄漏给模型 |
| 输入 | 题目对三列契约和特征来源的要求 |
| AI 建议 | 解析后只保留清洗文本，所有特征从同一列计算 |
| 人工判断 | 拒绝。保留 Subject+正文的 raw 和独立 cleaned；大写/标点/货币从 raw，关键词和词袋从 cleaned；普通头与附件排除 |
| 验证 | `test_raw_features_are_not_destroyed_by_cleaning`、输出列检查、合成邮件头反例 |

## Session 2：六包加载和实验切分

| 字段 | 内容 |
|---|---|
| 目的 | 防止同名目录覆盖并固定无泄漏训练边界 |
| 输入 | 六个 tar.bz2、共 7,449 封、`random_state=42`、`stratify=y` |
| AI 建议 | 全部解压后按目录加载，再在完整数据上 fit Vectorizer 后切分 |
| 人工判断 | 两处修改：直接读取 tar member 保留 source；先切分索引，只对训练 cleaned fit。完整数据 fit 会泄漏测试词表信息，即使标签未进入也不接受 |
| 验证 | 全量 7,449 封，六来源分别 2501/1401/251/501/1398/1397；训练 5,959、测试 1,490；集成测试断言 fit 行数 |

## Session 3：指标、误判与验收

| 字段 | 内容 |
|---|---|
| 目的 | 在规则和 NB 之间做可信比较 |
| 输入 | Accuracy/Precision/Recall/F1、正类 spam、门槛与四图要求 |
| AI 建议 | 只报告 Accuracy，并根据测试结果调阈值到达 95% |
| 人工判断 | 拒绝。正常邮件误拦截和垃圾邮件漏判成本不同，必须报告四指标与矩阵；最终测试集不用于循环调参，规则只作为固定可解释基线 |
| 验证 | NB Accuracy=0.9564、Precision=0.9885、Recall=0.9120、F1=0.9487，三项建议门槛均达到；报告保留真实 FP/FN 样例 |
