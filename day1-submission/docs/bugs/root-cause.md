# task-manager 根因分析

## Bug A：字符串优先级

### 假设 1：输入类型未标准化

- 验证：检查写入任务字典前的 `priority` 类型；字符串别名会原样进入字典。
- 结论：确认。根因是缺少统一的整数转换与别名映射。

### 假设 2：降序排序函数错误

- 验证：只传整数 `1/3/5`，`reverse=True` 能得到 `5/3/1`。
- 结论：排除。排序逻辑正确，异常来自字段类型不一致。

## Bug B：空标题

### 假设 1：只去空格但未检查结果

- 验证：`title.strip()` 后没有非空判断，空字符串仍进入任务字典。
- 结论：确认。

### 假设 2：测试错误地禁止空标题

- 验证：任务标题是展示、排序和筛选的业务标识；空标题无法形成有效任务，且课程用例明确要求抛错。
- 结论：排除。
