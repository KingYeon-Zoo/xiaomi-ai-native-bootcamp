# Day 1 提交包规格说明

## 目标

1. `rag-assistant` 能从固定课程 FAQ 检索相关片段，并在回答后输出 `[faq-XX]` 来源。
2. 资料外、混淆、空输入和纯停用词问题不会生成无依据回答。
3. `bug-fix-lab` 修复字符串优先级与空标题两个已复现问题，且不破坏正常排序和筛选。
4. 六类核心证据、Bug 证据和运行命令能让评审者独立复核。

## 非目标

1. 不开发 Web UI、用户登录或多人协作。
2. 不支持用户上传、PDF 解析或多个知识库。
3. 不引入向量数据库、Embedding 或语义重排。
4. 不调用真实外部模型 API；测试使用本地 Mock LLM。
5. 不把任务管理器扩展为完整产品，也不修复课程范围外的假设问题。

## 边界与失败行为

- 空问题或仅包含空格：提示用户输入问题，不调用回答模块。
- 纯停用词或 FAQ 无匹配：输出“资料中没有找到依据”，不输出虚假来源。
- 问题超过 200 字：截取前 200 字处理，程序不得崩溃或超时。
- Mock LLM 不可用：回答模块返回明确错误；自动化测试负责启动和关闭 Mock 服务。
- 标题为空或纯空格：任务管理器抛出包含 `title` 的 `ValueError`。
- 优先级为数字字符串或 `high/medium/low`：统一转为整数后参与排序。
