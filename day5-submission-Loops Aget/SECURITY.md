# 安全策略

## 支持范围

LOOPS 当前处于原型阶段。最新主分支会接收安全修复；历史提交不承诺单独维护。

## 报告漏洞

请不要在公开 Issue 中披露可利用细节、访问令牌、真实用户数据或未修复漏洞。优先使用代码托管平台的私密漏洞报告功能；若仓库尚未启用该功能，请仅创建不含利用细节的占位 Issue，等待维护者建立私密沟通渠道。

报告内容建议包含：

- 受影响模块与版本；
- 最小复现步骤；
- 可能影响；
- 已尝试的缓解方式；
- 是否包含密钥或个人数据。

## 密钥与数据

- 所有密钥只写入本地 `src/backend/.env`。
- `.env`、日志、上传内容、数据库导出与本地 AI 工具缓存不得提交。
- 若密钥曾出现在终端输出、提交或截图中，应立即撤销并轮换，而不是只删除文件。
- 演示数据库不得包含真实业务数据。

## 已知安全边界

当前管理侧 trace 与人工决定接口缺正式 RBAC，单进程队列也不具备生产级隔离与恢复能力。请勿把当前原型直接暴露到公网。
