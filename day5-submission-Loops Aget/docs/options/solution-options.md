# 方案路线

| 路线 | 核心形态 | 优点 | 局限 |
|---|---|---|---|
| 方案 A：机器学习流水线 | 规则、文本分类、图像分类、CLIP、融合决策 | 本地低延迟、高吞吐、成本稳定，复用度最高 | 复杂图文语境、证据解释、冲突恢复较弱 |
| 方案 B：单模型提示词 | 单个多模态 LLM 一次返回最终结论 | 代码和调用链最短，语义能力强于传统分类 | 仍是提示词工程，缺少工具、路由、权限隔离和恢复 |
| 方案 C：条件式 Agent 与 ML 双方案 | ML 负责快速场景；LangGraph Agent 负责复杂图文、冲突和人工闭环 | 同时兼顾效率、深度与证据链 | 状态、测试、数据口径和运维复杂度最高 |

最终选择方案 C。当前版本已实现两条能力和对比看板；统一在线风险路由是后续演进项。
