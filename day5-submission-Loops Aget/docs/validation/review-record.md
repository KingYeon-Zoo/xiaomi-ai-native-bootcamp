## 代码安全审查要点

- 策略门同时验证政策代码和 Evidence 来源；
- 用户状态接口排除 text 和 trace；
- 图片路径做类型、大小和解码校验；
- API Key 只从环境变量读取；
- 模型异常不会静默 allow。

## 仍需外部人工审查

仓库尚无独立安全审查、产品审查或政策专家签字。当前记录只能证明项目维护者与 AI 工具完成了逆向核验，不能替代生产发布前的外部审查。
