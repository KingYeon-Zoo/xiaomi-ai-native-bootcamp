# 风险与边界样例

## 已有代码或测试兜底

1. **提示注入**：正文要求模型忽略规则时，`RuleEvidenceTool` 生成 `REVIEW_PROMPT_INJECTION`，模型不能提升权限。
2. **伪造硬规则**：Evidence 来源不是 `rule/attack_tool` 时，即使包含 `HARD_BLOCK_*` 也不会短路。
3. **图文冲突**：风险路由检测 recommendations 不一致，升级 critic 与 arbiter。
4. **低置信或高风险**：低于 0.75 或 severity 大于等于 0.6 时升级。
5. **图片不可用**：格式仅限 JPEG/PNG/WebP，超过 8 MiB、损坏或不存在会令视觉 Agent 不可用，策略门转人工。
6. **模型非法结构**：有限重试；明确格式不兼容时降级 JSON 对象，最终仍由 Pydantic 验证。
7. **Graph 崩溃**：run 标记 failed，不默认 allow。
8. **人工恢复**：仅 `waiting_human` 可 resume，决定只接受 approve/reject。
9. **服务重启**：启动时重新排队 queued/running 任务。
10. **看板断网**：Mongo 无快照时后端回退，接口失败时前端回退，并显示数据源。

## 当前不能兜底

- 多实例重复消费、任务租约和 exactly-once；
- 管理端身份认证、细粒度授权与审计签名；
- 视频、多图、压缩炸弹和恶意解码器漏洞；
- 供应商长时间故障的跨模型灾备；
- 真实内容政策、标注集、漂移监控和阈值校准；
- 隐写、加密载荷和复杂跨语言对抗样本；
- 演示 seed 对真实数据库的误操作保护。

## 风险优先级

| 风险 | 可能性 | 影响 | 当前处理 | 后续动作 |
|---|---|---|---|---|
| 无鉴权访问 trace/人工接口 | 中 | 高 | 限本地演示 | 接入管理员身份与 RBAC |
| 单进程任务丢失或重复 | 中 | 高 | Mongo run + checkpoint | 外部队列、租约、幂等键 |
| 规则语境误杀 | 中 | 中 | 人工复核与来源限制 | 标注集校准和政策版本 |
| 云模型超时/配额 | 中 | 中 | 重试、不可用转人工 | 限流、熔断、备用供应商 |
| 演示 KPI 被误解为实测 | 中 | 中 | 页面来源标签和文档声明 | 答辩主动说明数据口径 |
| 前端包体过大 | 高 | 低 | 不阻塞 MVP | 路由级拆包和图表按需加载 |
