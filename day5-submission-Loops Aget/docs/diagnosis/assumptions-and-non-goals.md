# 假设与非目标

## 已有事实

- 后端使用 FastAPI、MongoDB、LangGraph 和 OpenAI Python SDK 的方舟兼容接口。
- `llm_api` 模式已经接入异步 Agent runtime。
- 视觉模型默认值为 `doubao-seed-2-0-lite-260428`。
- 文本、critic、arbiter 默认使用 DeepSeek 配置。
- 旧规则、ML 模型代码和指标仓储仍在仓库。
- 当前看板支持 Agent、ML、对比以及 1/24/168 小时切换。

## 设计假设

- 本地演示只运行一个 FastAPI 进程。
- MongoDB 可用，且演示数据库不包含需要保留的真实业务数据。
- 文本和视觉模型会返回可由 Pydantic 校验的结构化对象。
- 当前阈值用于工程演示，后续应由标注数据校准。

## 当前版本目标

- 建立完整 Agent 判断链和明确的权限边界；
- 保留 ML 快速方案，形成风险分流建议；
- 重构看板和确定性演示数据；
- 完成可复现的中文工程证据文档。

## 非目标

- 不在本轮重训或微调旧模型；
- 不把演示精度、吞吐、成本写成实测生产 KPI；
- 不建设生产级分布式队列、管理员鉴权和多租户；
- 不保存模型隐藏思维链；
- 不公开或提交 `.env` 中的密钥；
- 不把本地 AI 工具缓存提交到开源仓库；
- 不补造协作者、会议、用户访谈、云调用或测试结果。
