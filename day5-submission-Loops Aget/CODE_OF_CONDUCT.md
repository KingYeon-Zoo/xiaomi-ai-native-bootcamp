# 社区行为准则

LOOPS 希望保持一个专业、尊重事实、对不同经验水平友好的协作环境。

## 我们鼓励

- 对观点提出具体、可验证的反馈；
- 解释取舍、风险与证据，而不是评价个人；
- 主动披露不确定性、失败结果和已知限制；
- 尊重隐私、许可证与安全报告流程；
- 帮助新贡献者理解上下文和复现步骤。

## 不可接受

- 骚扰、歧视、侮辱或人身攻击；
- 未经许可公开个人信息、密钥或安全漏洞细节；
- 伪造测试、性能、贡献或审查记录；
- 利用项目渠道发布垃圾信息、广告或与项目无关的内容。

维护者可以编辑、隐藏或移除违反本准则的内容，并在必要时限制参与权限。遇到安全或隐私问题时，请优先按照 `SECURITY.md` 的私密流程报告。
