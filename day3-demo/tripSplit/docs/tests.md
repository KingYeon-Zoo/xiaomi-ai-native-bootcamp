## 后端 pytest

### test_trips.py — 旅行 CRUD

| 用例 | 输入 | 预期 |
|------|------|------|
| 创建旅行-正常 | `{"name": "南京游", "startDate": "2026-07-01", "endDate": "2026-07-03"}` | 200，返回含 id 的 trip |
| 创建旅行-名称为空 | `{"name": "", "startDate": "2026-07-01", "endDate": "2026-07-03"}` | 400 |
| 创建旅行-日期倒置 | `{"name": "测试", "startDate": "2026-07-03", "endDate": "2026-07-01"}` | 400 |
| 获取旅行列表 | GET /trips | 200，返回数组 |
| 获取旅行详情 | GET /trips/{id} | 200，返回含 members/expenses 的完整数据 |
| 获取详情-不存在 | GET /trips/不存在的id | 404 |
| 删除旅行 | DELETE /trips/{id} | 204 |
| 删除旅行-不存在 | DELETE /trips/不存在的id | 404 |

| 用例 | 输入 | 预期 |

### test_expenses.py — 账单 CRUD

| 用例 | 输入 | 预期 |
|------|------|------|
| 添加账单-正常 | `{"name": "酒店", "amount": 900, "payer": "小王", "participants": ["小王","小李"], "category": "住宿", "date": "2026-07-01"}` | 200 |
| 添加账单-金额为0 | amount: 0 | 400 |
| 添加账单-金额为负 | amount: -100 | 400 |
| 添加账单-payer不在members | payer: "不存在的人" | 400 |
| 添加账单-participants为空 | participants: [] | 400 |
| 编辑账单-部分字段更新 | 只传 amount: 800 | 200，其他字段不变，settlement 清除 |
| 删除账单 | DELETE /expenses/{eid} | 204，settlement 清除 |
| 编辑/删除后settlement清除 | 先结算，再编辑账单，GET 详情 | settlement 为 null |

### test_settle.py — 结算算法

| 用例 | 账单数据 | 预期 |
|------|----------|------|
| 3人均摊 | 酒店900(3人)+晚饭360(3人)+打车80(小王/小张) | 小王余额+440，小李-60，小张-380；转账：小张→小王 380，小李→小王 60 |
| 2人场景 | A付100(A/B均摊) | B→A 50 |
| 浮点精度 | 100.01元3人均摊 | 每人应付33.34（round），余额round后归零，总转账金额=总支出 |
| 总额对账 | 任意账单组合 | 所有转账金额之和 == 所有账单金额之和（取绝对值） |
| 余额归零 | 任意账单组合 | 结算后每人 balance 之和 == 0 |
