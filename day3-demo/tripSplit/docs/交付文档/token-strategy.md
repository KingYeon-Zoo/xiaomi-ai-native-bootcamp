## AI 协作中的 Token 控制

### 实测数据

| 任务 | Agent 消耗 | 控制手段 |
|------|-----------|----------|
| T1 后端骨架 | ~15k tokens | 只投喂 plan.md 相关段落 |
| T2 后端 API | ~30k tokens | 投喂 plan.md + tests.md |
| T3 后端结算 | ~20k tokens | 投喂算法 + 测试用例 |
| T4 前端骨架 | ~15k tokens | 只投喂依赖清单 + 路由 |
| T5 前端完整 | ~50k tokens | 投喂 plan.md + tests.md + API 文档 |
| **合计** | **~130k tokens** | — |

### 优化手段

1. **分任务投喂**：每个任务只给相关文档，不给全量
2. **阻塞即停**：3 轮无法解决立刻停下，避免无效消耗
3. **测试驱动**：先写测试再实现，减少返工
4. **提交隔离**：每任务独立提交，失败不影响已完成部分
