# 项目二：垃圾邮件智能过滤工具

> **难度等级**：Lv.2 入门级 | **总课时**：3 课时（每课时 45 分钟）
> **技术栈**：Python 3.10+ · pandas · scikit-learn · matplotlib
> **数据集**：SMS Spam Collection（UCI 经典数据集，5574 条短信）

---

## 项目目标

你的手机每天收到大量垃圾短信，你需要搭建一个自动过滤工具。

借助 AI 完成全流程：**文本清洗 → 特征提取 → 分类实现 → 评估对比 → 工具封装**。

核心能力：文本预处理 · 特征工程 · 规则过滤 · 朴素贝叶斯 · 混淆矩阵评估。

---

## 数据集

- **来源**：UCI Machine Learning Repository — [SMS Spam Collection](https://archive.ics.uci.edu/ml/datasets/sms+spam+collection)
- **规模**：5,574 条短信消息
- **标注**：ham（正常）4,827 条 · spam（垃圾）747 条
- **格式**：TSV 文件，两列 —— `label`（ham/spam）、`message`（短信内容）
- **特点**：类别不平衡（spam 约占 13.4%）

数据示例：

```
label   message
ham     Go until jurong point, crazy.. Available only in bugis n great world la e buffet...
ham     Ok lar... Joking wif u oni...
spam    Free entry in 2 a wkly comp to win FA Cup final tkts 21st May 2005...
ham     U dun say so early hor... U c already then say...
spam    WINNER!! As a valued network customer you have been selected to receivea £900 prize reward!
```

## Lesson 1：数据探索与文本清洗

### 你要做什么

1. **加载数据**：用 pandas 读取数据集，显示前 10 行
2. **数据探索**：用 AI 辅助生成代码，统计 ham/spam 数量及占比、检查缺失值、分析消息长度分布
3. **文本清洗流水线**（9 步）：
   1. 转小写（lowercase）
   2. 去除 HTML 标签
   3. 去除 URL 链接
   4. 去除邮箱地址
   5. 去除电话号码
   6. 去除特殊符号和标点
   7. 去除多余空格
   8. 去除停用词
   9. 过滤空消息
4. **讨论**：清洗是"有损的"——去噪的同时可能丢失有用特征（如 `!!!` 这种 spam 特征），你在去噪和保留信息之间如何平衡？

## Lesson 2：特征提取与分类实现

### 你要做什么

1. **特征提取**（6 个维度）：
   - 消息长度（字符数）
   - 大写字母占比（spam 常用大写强调）
   - 感叹号数量（spam 特征之一）
   - 关键词匹配（free、win、prize、cash、urgent 等）
   - 数字数量（电话号码、金额）
   - 货币符号（$、£、€）
2. **规则过滤器**：设定各特征得分权重 + 阈值，判定 spam/ham
3. **朴素贝叶斯分类器**：使用 scikit-learn 的 `CountVectorizer` + `MultinomialNB`
4. **两种方法对比**：分析规则过滤和朴素贝叶斯各自的优缺点

| `rule_filter.py` | 规则过滤器模块 |
| `naive_bayes.py` | 朴素贝叶斯分类模块 |

## Lesson 3：测试评估与报告总结

### 你要做什么

1. **混淆矩阵**：理解 TP/TN/FP/FN 的含义，计算 4 项评估指标：
   - 准确率（Accuracy）
   - 精确率（Precision）
   - 召回率（Recall）
   - F1 值
2. **讨论**："只看准确率够不够？如果把所有邮件都判为 ham，准确率也有 86.6%！"
3. **生成 3 种图表**：
   - 混淆矩阵热力图（两个模型并排）
   - 性能对比柱状图（规则过滤 vs 朴素贝叶斯）
   - 词频分布图（Top 20 高频词 ham vs spam）
4. **封装工具库**：整合为 `spam_filter/` 包
5. **撰写分析报告**：含误判样本分析
