# Plan — Day2 学习任务清单助手

## 一、模块划分

| 模块 | 文件 | 职责 |
|------|------|------|
| CLI 入口 | `cli.py` | 解析命令行参数，调用对应功能 |
| 任务管理 | `cli.py`（内部函数） | 加载任务列表、读写 `status.json` |
| 输出格式化 | `cli.py`（内部函数） | 格式化终端输出（任务列表、状态提示） |

> 项目很小，不需要拆多文件，`cli.py` 内部分 3 个职责即可。

---

## 二、数据结构

**任务列表**（硬编码在代码中）：
```python
TASKS = {
    "spec.md": "需求规格",
    "plan.md": "技术设计",
    "tasks.md": "任务拆解",
    "README.md": "项目说明",
    "ai-log.md": "AI 协作日志"
}
```

**状态文件**（`status.json`）：
```json
{
    "spec.md": false,
    "plan.md": false,
    "tasks.md": false,
    "README.md": false,
    "ai-log.md": false
}
```

- `false` = 未提交
- `true` = 已提交

---

## 三、风险

| 风险 | 影响 | 应对 |
|------|------|------|
| `status.json` 被手动删除 | 提交状态丢失 | 首次运行自动初始化，丢失不影响任务列表 |
| `status.json` 被篡改为非法格式 | 程序崩溃 | 读取时捕获异常，提示错误并重新初始化 |
| 文件名大小写不一致 | `submit` 命令匹配失败 | 统一转小写比较 |
